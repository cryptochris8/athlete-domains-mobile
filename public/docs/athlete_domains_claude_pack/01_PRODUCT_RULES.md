# Product Rules and Launch Rules

## V1 Goal
Launch the smoothest, simplest, and safest version of the Athlete Domains avatar ecosystem inside the existing mobile game/app ecosystem.

## Core Product Positioning
Athlete Domains in V1 is:
- a collectible avatar and cosmetics system
- a customization and identity layer
- a monetization and retention layer
- not a pay-to-win progression system

## Launch Principles
- performance first
- clarity first
- low bug risk
- low moderation / review risk
- clean App Store submission path
- future expandability

## V1 Features To Include
### Starter Avatars
Each new user owns 3 to 5 starter avatars by default.

### Locker Room
Users can:
- view owned avatars
- select active avatar
- equip shirt / jersey
- equip shoes
- preview locked items
- see rarity labels
- see founder / OG badge if applicable

### Cosmetics
Only support these categories in V1:
- shirt / jersey
- shoes

### Coins
Coins are earned from:
- gameplay
- wins
- daily reward
- rewarded ads

Coins are spent on:
- basic packs
- selected cosmetic items

### Packs
Supported in V1:
- Basic Pack
- Pro Pack
- optional Elite Pack
- optional Legendary Pack

### Duplicates
If a user receives a duplicate avatar in V1:
- convert duplicate into coins
- do not implement an upgrade tree in V1

### Monetization
Use:
- rewarded ads
- remove ads purchase
- coin packs
- optional starter pack

## V1 Features To Exclude
- battle pass
- live shop rotation
- rarity-based gameplay power
- advanced accessory slots
- cloud writes during routine browsing
- blockchain-gated in-app content
- in-app NFT wallet unlock flow

## App Store Safe Rule
NFT ownership must NOT directly:
- unlock iOS avatars
- unlock iOS cosmetics
- grant coins as an exclusive entitlement
- provide gameplay advantage
- bypass in-app purchase systems

## Safe NFT Positioning
The NFT collection can be positioned as:
- collectible athlete identity
- future Hytopia utility
- future ecosystem identity layer
- community / founder status signal

The mobile app must remain:
- fully usable without NFT ownership
- fully monetizable via standard iOS methods

## Founder / OG Layer
A founder layer may exist in V1 or V1.1 as long as it is mostly cosmetic and status-oriented.

Safe founder benefits:
- founder badge
- Discord role
- early announcements
- beta access
- early access to drops that later become broadly available

Avoid founder benefits that create direct paid gameplay advantage.
